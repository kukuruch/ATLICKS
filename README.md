# ATLICKS

Лёгкий текстовый мессенджер на Node.js с оранжевым интерфейсом. Клиент — обычные HTML/CSS/JavaScript без тяжёлых библиотек и внешних шрифтов. Сервер работает только на встроенных модулях Node.js; обновления чата идут через Server-Sent Events (SSE), без сторонних библиотек. Статические файлы сжимаются gzip при поддержке браузера.

## Что есть в первой версии

- Регистрация и вход по нику и паролю.
- Общий чат и личные сообщения между зарегистрированными пользователями.
- Сообщения находятся только в оперативной памяти и автоматически удаляются через час. Они не пишутся в файл или базу. При перезапуске сервера все сообщения исчезают раньше часа.
- Учётные записи сохраняются в обычном JSON-текстовом файле `users.json`. Пароли в файле не хранятся в открытом виде — сохраняются соль и PBKDF2-хеш.
- Тёмная тема включена по умолчанию; выбор тёмной/светлой темы сохраняется в браузере.
- Небольшая статическая страница, адаптация для смартфонов, лимит длины сообщения и базовая защита от частых запросов.

Ник должен содержать 3–20 латинских букв, цифр или `_`. Сообщение — до 1000 символов. Для ограничения расхода памяти хранится не более 1000 последних сообщений на один чат, плюс применяется срок жизни в 1 час.

## Запуск на компьютере

1. Установи Node.js версии 20 или новее.
2. Открой терминал в папке проекта.
3. Выполни `npm install`.
4. Запусти `npm start`.
5. Открой `http://localhost:3000`.

Локально регистрации сохраняются в `data/users.json`.

## Развёртывание на Render с сохранением пользователей

В репозитории уже есть `render.yaml`. Если импортировать его как Blueprint, он создаёт Node.js web service с каталогом данных `/var/data` на постоянном диске размером 1 GB. Приложение записывает регистрации в `/var/data/users.json`.

**Важно:** постоянные диски Render доступны платным сервисам. Бесплатный Render Web Service не поддерживает такой диск, а его локальные файлы могут исчезнуть при перезапуске/повторном развёртывании. Если разворачиваешь вручную, используй платный план и добавь диск с mount path `/var/data`, затем задай переменные:

- `NODE_ENV=production`
- `DATA_DIR=/var/data`
- `SESSION_SECRET` — длинная случайная секретная строка

Build command: `npm install`  
Start command: `npm start`  
Health check path: `/health`

Сохраняются только регистрации, так как папка с `users.json` находится на постоянном диске. Сообщения, активные соединения SSE и список подключённых пользователей специально не сохраняются и пропадают после перезапуска.

## Файл регистраций

Пример структуры `users.json`:

```json
[
  {
    "username": "orange_cat",
    "salt": "hex-соль",
    "passwordHash": "PBKDF2-хеш",
    "createdAt": "2026-10-14T12:00:00.000Z"
  }
]
```

Не публикуй этот файл и никогда не сохраняй пароли в открытом виде. Для серьёзного публичного сервиса перед запуском стоит добавить восстановление аккаунта, проверку электронной почты и резервное копирование.
